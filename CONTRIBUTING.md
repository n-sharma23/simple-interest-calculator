# Contributing to Simple Interest Calculator

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## Reporting a bug

Open an [issue](https://github.com/n-sharma23/simple-interest-calculator/issues) and include:

- the principal, rate and time you entered
- the result you expected and the result you got
- your Python version, if you ran the sample code

## Suggesting an enhancement or idea

Open an issue describing the problem it solves and how you'd like it to work.

## Submitting a change

1. Fork the repository and create a branch from `main`.
2. Make your change. Keep it focused on one thing.
3. If you change the formula or the sample code, update `README.md` to match.
4. Open a pull request that explains what you changed and why.
